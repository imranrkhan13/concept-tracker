A simple web app to track your learning progress as a developer. Keep note of concepts you’re learning, your comfort level, projects you’ve used them in, and any confusion you have.

This is just the starting version — in the future, we plan to upgrade it to React, Node.js, and more advanced features.

🧠 Features (Current Version)

Add new concepts with:

Concept name

Understanding level (Learning, Comfortable, Mastered, Confused)

Projects used

Optional confusion notes

Track your learning journey in a list

Filter concepts by understanding level

Delete or edit concepts

Basic stats:

Total concepts

Mastered concepts

Projects applied

Concepts needing review

Fetch learning resources from StackOverflow (basic version)

AI summary placeholder for each concept

🛠️ Technologies Used

HTML, CSS, JavaScript

LocalStorage to save concepts in the browser

StackOverflow API to fetch learning resources

Later versions will include: React, Node.js, and possibly a database

📦 How to Use

Open index.html in your browser

Add new concepts using the form

View your learning journey and filter concepts

Click “Resources” or “AI Summary” buttons for extra info (basic version)

📈 Next Steps

Convert this app to React for better UI and state management

Build a Node.js backend to store concepts in a database

Add user authentication so multiple people can track their learning

Implement AI-powered summaries for concepts

Improve resource fetching and allow bookmarking external links

⚡ Note

This is just the starting point. The goal is to make a full-stack developer learning tracker with advanced features in the near future.
