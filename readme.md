

# 🎯 Developer Learning Tracker

Hey there! This is a little web app to **track your learning as a developer**. You can keep track of concepts you’re exploring, how comfortable you are with them, the projects you’ve used them in, and even the stuff that’s confusing you.

For now, it’s **just the starting version**—think of it as a prototype. Eventually, we’ll make it slicker with **React, Node.js, and all the fancy backend stuff**, but for now, this is enough to play with.

---

### 🧠 What you can do right now

* Add new concepts with a name, your current understanding level (Learning, Comfortable, Mastered, Confused), any projects you’ve used them in, and optional notes if something’s tripping you up.
* See all your concepts in one place, **filter by your understanding level**, and keep track of your progress.
* Edit or delete any concept if you need to fix something.
* Check out basic stats: how many concepts you’ve added, mastered, used in projects, or need to review.
* Click the Resources button to fetch some **learning links from StackOverflow** (basic version).
* AI Summary is just a placeholder for now—coming soon.

---

### 🛠 How it’s built (so far)

* HTML, CSS, JavaScript
* LocalStorage in the browser to save your progress
* StackOverflow API to fetch resources
* Nothing fancy on the backend yet—just the front-end prototype

---

### 📦 How to use it

Open `index.html` in your browser, add a few concepts, play around with the filters, check out your stats, and click Resources or AI Summary to see some extra info. That’s it!
